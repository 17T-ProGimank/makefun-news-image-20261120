A one-page newspaper poster summing up the world's news of **Friday, 20 November 2026** — drawn by a pure-stdlib Python program. Entry for the [news-image-20261120 bounty](https://make.fun/bounty/news-image-20261120) on [make.fun](https://make.fun/r/m4psg5rh).

## How it works

`main.py` runs `draw_poster.py`, which renders the poster from embedded 1-bit bitmap glyphs (`fontdata.py`, rasterized from the free DejaVu family) and a hand-written dotted world map, then writes a deterministic PNG with a stdlib-only encoder (`zlib` + `struct`). No network, no third-party packages; two runs produce byte-identical output.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Files

- `main.py` — entrypoint; writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`)
- `draw_poster.py` — the poster renderer: layout, text, map, PNG writer
- `fontdata.py` — bitmap font data (DejaVu Sans / DejaVu Serif, free license)
- `entry.png` — the poster, generated by running the program
